# CSF_Lab03
Aim: To develop a clear understanding on control structures of Python by implementing conditional statements(if, elif, and else), loop(for and while), break and continue statements, and functions.

List of programs:
1. To check numbers(+ve, -ve or zero)
-> Determination of whether the numbers are positive, negative or zero through the use of if-else statements and comparison approach.
2. To check even or odd number
-> Testing whether the number is even or odd by introducing modulus operator.
3. Largest between two numbers
-> Comparison method and if-else method of checking numbers.
4. Largest among three numbers
-> Finding the largest of three numbers through nested use of if-else statements since we have three variables and then we have to compare them all to obtain the largest of them.
5. Grade comparison
-> Issue the grade based on his/her score by use of if-else and comparison.
6. Simple calculator
-> Writing calculator with the arithmetic operators and comparison operator and if else statements.
7. Printing numbers(1-10)
-> The for loop was used to create numbers between 1 and 10.
8. Printing even numbers(1-20)
-> With the help of for loop and operator of modulus we created numbers between 1 and 20, however with only even numbers.
9. Sum of first ten numbers
-> Sum of first 10 numbers is obtained by increment method which adds till 10.
10. Multiplication table
-> Multiplication table of for loop.
11. Printing numbers(1-5)
-> With the help of the while loop we created numbers through the conditions 1 to 5.
12. Sum of numbers from 1 to n
-> Addition of numbers incremental method which adds first to the second and so on to the n th term(eg. 1+2+....+n)
13. While loop(zero)
-> We created a program which will continue running until the user types 0.
14. Giving break as output.
-> Loop then break after the output needed.
15. continue to print out.
-> loop then continue by obtaining the desired output.
16. Targetting in a list
-> targeting the numbers in a list using loop and if-else statements Retrieving the numbers in a list using list and then targeting the numbers in a list.
17. Printing "Hello, world!"
-> To print "Hello, world!" by defining the function.
18. To find the square of a number
-> To obtain the square of a number writing it down as the f(eg. 6 x 6 = 36)
19. To add some numbers with a function.
-> Addition of two numbers by defining the function.
20. To test even or odd with the help of function.
-> Checking numbers with a modulus operator and if-else statement with the definition of a function.
21. To find factorial of a number
-> Computation of the factorial of a number using if-else statement following the definition of a function.
22. Producing multiplication table.
-> Producing multiplication table with the help of a loop once a function was defined.
23. Even or odd function
-> Verifying the number through the application of if-else and loop upon defining the function.
24. Calculator
-> Production of calculator with the use of while loop and if- else statements once the operator function has been defined.
